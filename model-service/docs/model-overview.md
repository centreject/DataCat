## 하는 일

Spring이 사진이나 음성을 보내면, 무엇이 보이는지와 방문객이 무슨 용건으로 왔는지를 돌려준다. Pi·앱과는 직접 통신하지 않는다.

```
Pi ──사진·음성──▶ Spring ──▶ 모델 서비스 (이 폴더, 포트 8000)
                    ▲            ├ 이미지 인식: 사람·물품·동물
                    └── 결과 ────┤ 음성 인식: 음성 → 글자
                                 └ 언어 모델: 글자 → 용건 9종 + 20자 요약
```

## 모델 구성

| 역할 | 모델 | 크기 | 고른 이유 |
|---|---|---|---|
| 사람·동물 인식 | YOLO11s (COCO 사전학습) | 약 20MB | 빠르고(이미지 1장 약 35ms) 사람 인식이 안정적 |
| 물품 인식 | YOLOE-11s (글자로 찾을 물건을 지정) | 약 30MB | 학습 없이 "상자·봉투·꽃다발·케이크 상자" 같은 이름만으로 찾음 |
| 음성 인식 | faster-whisper large-v3-turbo | 약 1.6GB | 한국어 정확도가 높고 빠름 |
| 용건 분류·요약 | Qwen3-4B-Instruct | 약 8GB (lite에서는 4bit로 약 2.5GB) | 한국어 지시를 잘 따르고 8GB GPU에 다른 모델과 같이 들어감 |

- **따로 학습시키지 않았다.** 공개된 사전학습 모델을 그대로 쓰고, 지시문(프롬프트), 예시, 규칙으로 우리 상황에 맞췄다. 물품 전용 학습은 팀 사진이 모이면 할 예정이다.
- 용건 9종과 배송 세부 유형 8종은 덕민님 상황 분류 기획서를 따른다. 분류를 바꿀 때는 [`app/language/purposes.json`](../app/language/purposes.json) 한 파일만 고친다.
- 언어 모델이 실패하면 키워드 규칙으로 대신 답하고 `RULES_FALLBACK` 표시를 붙인다. 모델 하나가 고장 나도 나머지는 계속 동작한다.
- 음성은 메모리에서만 처리하고 디스크에 저장하지 않는다(테스트로 확인).

## 성능 (RTX 3060 Ti 8GB, lite 프로필, 2026-10-04)

| 항목 | 결과 | 목표 |
|---|---|---|
| 음성 처리 전체 (음성 → 용건·요약) | 보통 1.1초, 느릴 때(p95) 1.5초 | 4초 이내 |
| 이미지 인식 1장 | 보통 35ms, 느릴 때 49ms | 0.3초 이내 |
| GPU 메모리 (세 모델 함께) | 약 6.2GB | 8GB 안 |
| 음성 인식 글자 오류율 (합성 음성, 잡음 포함) | 3.9~5.3% | 15% 이하 |
| 용건 정확도 (평가 100문장 / 시험 64문장) | 98% / 98% | 90% |
| 긴급·위협 감지율 (평가 / 시험) | 100% / 90% | 95% |
| 배송 세부 유형 (평가 / 시험) | 83% / 86% | 80% |
| 사람 / 상자 / 봉투 / 동물 인식 | 93% / 83% / 80% / 97% | 95% / 85% / 85% / 90% |

"시험 문장"은 튜닝에 쓰지 않은 문장이라 실제에 가까운 수치다. 합성 음성과 공개 사진으로 잰 값이라 실제 현관 녹음·사진으로 다시 재야 한다.

## 알려진 약점

- 물품 인식이 목표(85%)보다 낮다 → Spring에서 "사람 없음 + ToF 감지 = 물품 도착"으로 보완을 제안했고, 팀 사진으로 학습할 예정.
- 돌려 말한 위협("가만 안 둬")을 놓친 적이 있다 → 보강 예정.
- `purpose`는 방문객이 말로 바꿀 수 있으니 출입·보안 판단에 쓰지 않는다.

## RTX 3090에서 실행하기

이미지(12GB)와 모델 파일(약 10GB)이 커서 링크로 주고받지 않고 저장소에서 직접 빌드한다. NVIDIA 드라이버 591 이상, Docker의 GPU 지원(`--gpus all`)이 필요하다.

```bash
docker build -t datacat-model model-service
docker run --gpus all -p 8000:8000 -e MODEL_PROFILE=full -v datacat-models:/models datacat-model
curl http://localhost:8000/health        # {"status":"ok","profile":"full"}
```

- 3090(24GB)은 4bit 압축 없이 더 정확한 `full` 프로필을 쓸 수 있다. 아직 측정 전이라 문제가 있으면 `MODEL_PROFILE=lite`로 바꾼다.
- 첫 실행은 모델 파일을 내려받느라 수 분~수십 분 걸리고, 그 뒤로는 인터넷 없이 뜬다.
- GPU 없이 연동만 시험할 때는 가짜 서버를 쓴다: `docker build -f model-service/Dockerfile.mock -t datacat-model-mock model-service` (README "가짜 모델 서버").
