# 실제 현관 데이터 수집 안내 (R1)

지금 AI 수치는 공개 사진과 합성 음성 기준이다. 실제 현관 카메라·마이크로 찍고 녹음한 데이터로 다시 재고,
사람 인식 기준값(Q2), 보냉백·배달 가방 오탐 기준값(Q4), 먼 거리 음성(R4)을 정한다.

## 원칙

- **저장소에 올리지 않는다.** 사진·녹음은 `model-service/data/real/`(git 제외)에만 둔다. 얼굴, 호수, 전단지, 목소리가 담긴다.
- 녹음하는 사람에게 용도(정확도 평가, 팀 내부)를 말하고 동의를 받는다.
- **test 나눔은 보기만 한다.** 결과를 보고 고치지 않는다. 고칠 때는 tune 나눔만 본다.
- 장치는 실제 설치 그대로: Pi + Camera Module 3 Wide(설치 높이·각도 고정), USB 마이크 입력 100%.

## 찍을 것 (사진, `photo/`)

| 종류 | 내용 | 목표 수량 | labels.csv `truth` |
|---|---|---:|---|
| 사람 | 문 앞 50·100·150cm, 정면·옆, 낮·밤 | 30장 이상 | `person` (물건을 들면 `person+package`) |
| 물품 | 상자, 비닐봉지, **음식 배달 봉투, 보냉백** | 종류별 10장 이상 | `package` |
| 빈 문 앞 | 낮·밤, 우산·가방·신발이 놓인 경우 포함 | 30장 이상 | `empty` |
| 동물 | 가능하면 | 몇 장 | `animal` |

- 파일 이름은 자유. labels.csv에 한 줄씩: `photo/파일.jpg,photo,person,,,100,night,test`
- 같은 장면을 조금씩 바꿔 여러 장 찍으면, 3장 중 1장꼴로 `test`, 나머지는 `tune`.

## 녹음할 것 (음성, `voice/`)

```
cd model-service
python -m eval.real_data sheet            # data/real/recording_sheet.md 와 labels.csv(음성 216줄) 생성
```

- 문장표의 72문장을 입에서 마이크까지 **20·50·100cm**에서 한 번씩 읽는다(약 40분).
  - test 45문장 = 김덕민 시험 문장(튜닝에 쓰지 않은 문장), tune 27문장 = 개발 문장(용건마다 3개)
- 파일은 16kHz·mono·16bit WAV, 이름은 표 그대로(예: `voice/d_delivery_01_50cm.wav`).
- 거리를 줄이고 싶으면 `--distances 20,100`.

## 평가

```
python -m eval.real_data eval --split test   # GPU. 있는 파일만 잰다
```

사진은 사람·물품 찾은 비율과 빈 사진 오탐을 빛·거리별로, 음성은 글자 오류율·빈 받아쓰기·용건 정확도·긴급·위협을 거리별로 보여 준다. 결과는 `eval/README.md`에 기록한다.
