# 정식 안내 음원 (2026-10-31 팀 투표로 확정)

팀 투표(A/B, 이름 가림)에서 인사·완료 모두 B 채택: 인사는 아래 `greeting.wav` 그대로, 완료는 4차 청취의 `completion_L`(밝지만 차분하게)로 바꿈 — 이전 완료 음원은 `completion_alt.wav`로 남김. **10/31 이전에 Pi로 복사한 `completion.wav`는 다시 복사해야 한다.**

Pi `raspberry-pi/sounds/`에 이 이름 그대로 복사하면 된다. 16kHz·mono·16bit, Qwen3-TTS 1.7B CustomVoice "Sohee"(Apache 2.0).

| 파일 | 문구 (서버 프리셋과 같음) | 원본 | 말투 지시 |
|---|---|---|---|
| `greeting.wav` | 마이크에 말씀해 주세요. | blind2 `greeting_Y` (1순위) | 경쾌하고 따뜻하게, 조금 높은 음 |
| `greeting_alt.wav` | 〃 | blind2 `greeting_X` (2순위) | 〃 |
| `completion.wav` | 접수되었습니다. | blind4 `completion_L` (팀 투표 채택) | 밝지만 차분하게, 음절에 힘주지 말고(영어 지시) |
| `completion_alt.wav` | 〃 | blind3 `completion_P` (민중 1순위였음, 강세 없음·약간 어눌) | 경쾌하고 따뜻하게 |
| `fallback.wav` | 일시적인 오류로 접수할 수 없습니다. 잠시 후 다시 시도해 주세요. | blind2 `fallback_X` | 경쾌하고 따뜻하게 |

완료 안내는 짧은 문장이라 밝은 말투를 세게 주면 음절마다 힘이 들어갔다(blind3 Q·R: "접!수!되었!습니다!"). 밝기와 함께 강세가 없는지도 들어 보고 골랐다.
녹음 알림 문구("안녕하세요. 용건을 말씀해 주시면, 집주인에게 전달됩니다.")나 "전달했습니다. 감사합니다."로 정해지면 같은 방식으로 다시 만든다(`../tools/`).

완료 안내 4차(blind4, "밝지만 차분하게, 음절에 힘주지 말고" 16개): 억양 폭을 줄이면 강세는 사라지지만 너무 평평해지면 뭉개진 소리가 된다(K: "한 대 맞아 부은 사람 같음"). 그래서 P를 유지하고 L을 예비로 뒀다가, 10/31 팀 투표에서 L이 채택됐다.
